信号的卷积：原理、性质与变换域分析

/ 信号分析与处理 / 信号与系统 / 卷积 已索引 1.8 MB 2026-10-12 33 块

信号与系统里，卷积不是一条需要死记的公式，而是一种把复杂输入拆成简单冲激、再把系统响应叠加起来的工作方法。理解这一点，后面的卷积定理、频域相乘才不会是孤立的结论。

2.1从叠加到卷积

设系统的输入为 x(t)，冲激响应为 h(t)。把输入分解成一串加权冲激：

x(t) = ∫ x(τ) δ(t − τ) dτ
对线性时不变系统，每个冲激产生一个平移后的 h(t − τ)，叠加即得输出。

因此，系统的零状态响应可以写成卷积积分 [2]：

y(t) = x(t) * h(t) = ∫ x(τ) h(t − τ) dτ

这个式子的直观含义是：输出在某一时刻的值，等于输入在过去所有时刻的贡献之和，而每个贡献的权重由系统对“多久以前的输入”还记得多少决定。

2.2三个可以直接手算的性质

卷积的交换律、分配律和结合律，使我们可以先算最简单的部分，再把结果搬回原来的问题。与冲激函数卷积不改变波形，与阶跃函数卷积则相当于积分，这两条在考试和工程估算里出现得最多。

更值得注意的是，时域卷积对应频域相乘。这条定理把“卷积很难算”的问题转成了“乘法很好算”的问题，也是 FFT 能在工程里大规模使用的原因之一 [3]。

2.3什么时候不该直接算卷积

当信号长度达到 10⁵ 量级时，直接做离散卷积的代价是 O(N²)。这时应当转到频域，用 FFT 计算乘积再变换回来；代价变成 O(N log N)。这不是数学上的新结论，而是同一结论在计算层面的用法。

Q
为什么这里说“时域卷积对应频域相乘”？能结合上面的公式解释吗？
A

把卷积积分代入傅里叶变换，交换积分次序后会得到 Y(jω)=X(jω)H(jω)：时域的卷积运算，在频域变成了逐点相乘 [1]。

所以上面那条积分式并不是只能硬算：先对 x 和 h 做变换，相乘后再逆变换，往往更快。FFT 的价值就在这里 [2]。
