### 3. 功能清单（要点）

- 导入：docx/doc/pdf/pptx/md/txt；PDF 无文本页走 Windows OCR；`.doc` 依赖本机 Word。
- 检索：FTS5 trigram + 本地向量（源码版）；RRF 融合、标题稀有度、同义词/错别字/表格/领域提示。
- 问答：多模型（DeepSeek/智谱免费/硅基流动/Ollama）、引用可点、追问、历史（置顶/收藏/标签）、成本与缓存。
- 导出：问答笔记 / 复习提纲（速览·分节·公式表·易错·自测·来源）；勾选、附摘录、合并、按知识树归章；零依赖 OOXML。
- 导图：树生成、节点/连线/画笔/文本框、缩放平移、折叠隐藏、词云（可改字号颜色、虚线关联、点词 AI）、PNG/SVG、JSON 存档。
- 运维：自动/手动备份、重建索引、向量索引、回收站、密钥管理（DPAPI；换机需重填）。
- 安全：仅监听 127.0.0.1；JSON+Origin+Host+Sec-Fetch-Site 校验；请求体 32MB 上限；`/api/open` 限资料库内；导入扩展名白名单；安全响应头。
- 兼容：启动前自动清除 MOTW（`doclib/motw.py`）；包内 `解除锁定.bat`（GBK+936，已修引号/编码 bug）。

### 5. 已知限制与技术债

1. 真实问句召回 81.8%（约 1/5 首检未进前 8）。
2. 打包版无语义检索（未含 onnxruntime/numpy/sqlite-vec）。
3. 提纲是规则抽取，质量受原答案影响；无 TOC 域、无术语表/对照表自动生成。
4. 无登录（本机信任模型）；导入支持本地任意文档路径（限扩展名）。
5. 无速率限制；未知异常仍回 `str(e)`（可能含路径）。
6. 导图 JSON 无数据库索引（列表靠扫描）；词云取词质量一般。
7. 单用户、单实例、无云同步。
8. 打包会清空 `dist\DocLib`（必须走 `打包.bat`）。
9. 分发经 rar/zip 会带 MOTW（已自愈，但仍建议附 `解除锁定.bat`）。

## 二、第二版想法评估

### 总体判断

四个方向都成立，但**价值密度差别很大**。建议按"可量化收益 / 改动风险"排序，而不是平均用力。

| 方向 | 价值 | 难度 | 风险 | 建议优先级 |
|---|---|---|---|---|
| 强化 AI 检索 | ★★★★★（直接决定"答得对不对"） | 中高 | 中（易过拟合、成本） | **P0** |
| 修复漏洞/健壮性 | ★★★★ | 低中 | 低 | **P0（顺手做）** |
| 改良不顺手的地方 | ★★★★ | 低中 | 低 | **P1** |
| 拓展新功能 | ★★★（易膨胀） | 高 | 高（范围失控） | **P2 分批** |

### P0-1 强化检索（最值得先做）

**现状证据**：66 条真实问句召回 81.8%；失败类型主要 3 类：
- 口语化与教材术语不对齐（"怎么用对称性判断"→"对称性判据"）
- 章级/跨节问题（"这一章讲什么"）与块级检索粒度不匹配
- 同义/近义章节竞争（级数 vs 变换 vs 拉普拉斯）

**可做的 5 件事**（按性价比）：
1. **真实问题集**：需要你提供 20–30 条真实提问及"期望命中的章节"；这是所有调优的度量尺（没有它就只能拿合成题自嗨）。
2. **查询改写层**：规则同义词 + LLM 改写（可用免费 glm-flash）→ 多查询融合召回。
3. **章节级路由**：先用标题/文档级信号定位章节，再在章内做块检索（解决粒度错配）。
4. **重排（rerank）**：小模型或 LLM 对 top-20 重排取 top-8；成本可控（只排 20 条）。
5. **失败样本回灌**：每次人工纠正后把该问加入回归集，形成"越用越准"。

**目标**：真实问句召回@8 81.8% → **90%+**；同时保持 21/21 回归不退化。

### P0-2 漏洞与健壮性（低成本）

已完成：CSRF/Origin/Host/跨站 GET/路径白名单/类型白名单/请求体上限/安全头/MOTW 自愈。
建议 v2 补：
- 未知异常统一"内部错误"，日志保留详情（防路径泄露）
- 简单限流（防脚本刷导入/问答）
- 审计脚本纳入发布前必跑（已 60 项）
- 依赖版本锁定（pythonnet/clr_loader/webview/pyinstaller）
- （可选）代码签名，降低 SmartScreen 干扰

### P1 体验改良（用户感知强、风险低）

建议清单（按收益）：
1. **首次启动向导**：三步引导（配 API → 导入 → 试问一题），空状态不再"空白页"。
2. 窗口图标、窗口尺寸/位置记忆、关闭确认（最小化到托盘可选）。
3. 设置项导入/导出（换机不用手抄配置）+ 备份/恢复可视化。
4. 导入进度与失败原因可视化（大批量导入时）。
5. 知识树维护：批量挂载、查重、非学科文档隔离/隐藏。
6. 导出：保存位置可选、模板可选、导出前预览。
7. 错误文案统一（把"退出码 5"这类转成人话+操作指引）。

### P2 拓展功能（分批，避免一次做太多）

按"用户价值/实现成本"：
1. **复习资料规范化**：术语表、对照表、TOC 域、公式转 OMML（与你已有的 review-notes 规范对齐）。
2. **多课程/多库**：一个程序管多门课（独立 data 或库切换）。
3. **问答模板**：自定义导出模板（问答/提纲/错题本）。
4. **PDF/图片预览内嵌**：不弹外部程序。
5. **检索增强可视化**：命中片段高亮、来源跳转定位。
6. **局域网/多端**（若确有需求）：需先补鉴权与限流。

不建议现在做：移动端、云同步、账号体系（与"纯本地"定位冲突，成本高）。

## 五、需要你定的 4 件事

1. **真实问题集**：能否提供 20–30 条（问题 + 期望章节）？没有它，检索调优只能靠合成题。
2. **功能取舍**：v2 优先"检索"还是"导出规范化"？两者都做的话，建议检索先行。
3. **多课程/多库**：是否有需求（会改数据目录与 UI 结构）？
4. **联网能力**：是否允许"用免费模型做查询改写/重排"（有少量 token 成本，质量提升明显）？

## 六、风险与护栏

- **护栏**：任何检索/导出改动必须过 21 条回归 + 导出 7 组；打包走 `打包.bat`；分发只用干净包。
- **数据**：v2 迁移前先备份 `dist\DocLib\data`；禁止 AI 写真相层。
- **范围**：每个阶段结束可交付、可回滚；不合并"大重构"。
- **分发**：zip + `解除锁定.bat`；个人包永不外发；MOTW 自愈为兜底。
- **成本**：LLM 改写/重排只用于提问路径，单次可控；免费模型优先。
